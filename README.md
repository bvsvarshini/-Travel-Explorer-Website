# 🌍 Travel Explorer Website

## 📌 Overview
Travel Explorer is a responsive web application that allows users to explore travel destinations and view real-time weather conditions using external APIs.

The project demonstrates front-end development skills along with API integration to deliver dynamic, location-based information.

---

## 🚀 Features
- Responsive design (mobile, tablet, desktop)
- Explore popular travel destinations
- Real-time weather data for selected locations
- Dynamic content using external APIs
- Clean and interactive user interface

---

## 🛠️ Tech Stack
- HTML5  
- CSS3  
- JavaScript  
- REST APIs (Weather API)  
- Unsplash API (for travel images)  

---

## 📂 Project Structure
Travel-Explorer-Website/
│── index.html
│── style.css
│── script.js
│── images/

---

## ⚙️ How It Works
1. Users browse destinations on the website  
2. The application fetches real-time weather data via API  
3. Weather details are displayed dynamically  
4. Images are loaded using Unsplash API
